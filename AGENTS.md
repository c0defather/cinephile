# AGENTS.md

«Киноманьяк»: подбор фильма по сложному запросу только из своего каталога, ответ проверяет код.
Контракт поведения: `SPEC.md`. Порядок работ: `PLAN.md`.

## Состояние репозитория

- Ветка `main`, remote `origin` (github.com/c0defather/cinephile).
- Git-автор: `c0defather`, `kuanysh.zhunussov@gmail.com` (локальный конфиг репозитория).
- Файлы кода появляются по шагам `PLAN.md`; документы (SPEC.md, AGENTS.md, PLAN.md) идут раньше кода.

## Команды

- `uv sync` (Python 3.12 из `.python-version`; `uv.lock` коммитится)
- `uv run pytest -q`; один файл: `uv run pytest tests/test_pick.py -q`
- `uv run kino.py "запрос"`, `uv run check.py`, `uv run show.py`
- Автопроверка из раздатки (после коммита, она берёт `HEAD`):
  `python3 -I ПУТЬ/kino_check.py . [--live]`

## Стиль кода

Как в `chef.py` лекции 3: плоский скрипт, константы вверху (`MODEL`, `LIMIT`, `PRICE`, `INSTRUCTIONS`),
Pydantic-схема, функция `log()` пишет `calls.jsonl`, функция выбора ловит ошибки и возвращает исход,
печать внутри функции. Комментарии и тексты — по-русски, короткие. Без лишних слоёв и классов.

## Детали, которые легко сделать неправильно

- `pick(client, model, query, films)` возвращает `(outcome, ids)`. При любом исходе, кроме `ok`, `ids == []`.
- Печать фильмов внутри `pick`, не в `__main__`. Название, год, минуты, описание берутся из переданного `films`.
- `pick` не читает `films.json`. Каталог читается в `__main__` и передаётся.
- При импорте `kino.py` ничего не печатается и не запускается (`if __name__ == "__main__"`).
- Каталог в промпте: `json.dumps(films, ensure_ascii=False)` в теге `<каталог>`, запрос в `<запрос>`.
  Без `ensure_ascii=False` автопроверка не найдёт названия в промпте.
- Чужой id: пользователь не видит ни одного фильма (не только чужой), исход `invalid`, `rejected` в журнале.
- `ValidationError` ловится и даёт `invalid`. Если `film_id` задан через `Literal`, список строится из переданных `films`.
- Для Rare `film_id` — обычная строка, иначе замерять «чужие id до проверки» нечего.
- Строки журнала от вызова фильтров: `"step": "filters"`, от выбора: `"step": "choice"`.
- В `request` журнала: текст запроса и список id, не весь каталог.
- Модель в журнале — то, что передано в `pick`, а не константа.
- Локальная `qwen3.5:4b`: `reasoning_effort="none"`, иначе один вызов идёт минуты.
- Резерв «облако упало → локальная» живёт в `__main__`, не в `pick`: `pick` возвращает `no_connection` как есть.
- Эксперименты с реальными моделями пишут в `calls.jsonl`. Тесты и проверки не должны ходить в сеть.

## Тесты

- Реальная сеть запрещена. Клиент подменяется заглушкой (`SimpleNamespace`), как в семинаре.
- Для исключений SDK нужен `httpx` и `openai.APIConnectionError(request=...)`.
- Заглушка собирает ответ через парсер SDK, чтобы отказ, обрезка и ошибка схемы вели себя как у настоящего клиента.
- Каталог для тестов — маленький свой, не `films.json`.

## Секреты

- `.env` не открывать, не печатать, не коммитить. Ключи API и токен Telegram только оттуда.
- Перед коммитом: `git diff --cached` без ключей. Автопроверка ищет `sk-...` во всей истории, один случайный коммит с ключом её провалит.

## Как работать

1. Один шаг `PLAN.md`: сначала падающий тест по критерию `SPEC.md`, затем минимальный код. SPEC.md не менять без причины.
2. `uv run pytest -q` зелёный, затем один коммит с номером шага (`03: схема ответа и промпт`).
3. Не ослаблять и не удалять тесты ради зелёного прогона; не использовать `--no-verify`.
4. Числа в README брать только из настоящих запусков (`calls.jsonl`, вывод `check.py`, `show.py`).

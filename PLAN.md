# PLAN.md — реализация «Киноманьяка» по SPEC.md

Каждый шаг: сначала падающий тест, затем минимальный код до зелёного, затем `uv run pytest -q`
и отдельный коммит. Сообщения коммитов по-русски с номером шага. Шаги 00–14 — Common (обязательный),
дальше Rare, Epic, Legendary: они независимы, порядок можно менять.

## Решения

- Каркас: плоский `kino.py` в стиле `chef.py` (лекция 3), без пакета.
- Каталог: Wikidata (SPARQL) + `films_kz_example.json` + дособранные казахстанские фильмы. Скрипт сборки `build_catalog.py`.
  Источник и дата в README. Описания по-русски можно сгенерировать моделью, остальные поля только из источника.
- Модели: основная — локальная `qwen3.5:4b` (Ollama, `reasoning_effort="none"`); облачная — OpenAI (`gpt-6-luna`).
  Резерв «облако → локальная» в `__main__`.
- Тесты: `pytest`, заглушка клиента, без сети.

## Common

- [ ] **00 — Документы.** `SPEC.md`, `AGENTS.md`, `PLAN.md`. Коммит: `00: SPEC, AGENTS и PLAN`.
- [ ] **01 — Каркас.** `pyproject.toml` (Python 3.12; `openai`, `pydantic`, `python-dotenv`; dev `pytest`;
  `pythonpath = ["."]`), `.python-version`, `.gitignore` (`.env`, `.venv`), `.env.example`, `kino.py` с пустым `pick`
  и `if __name__ == "__main__"`, `uv.lock`. Тест: `tests/test_import.py` — импорт без вывода, `pick` вызываема.
  Коммит: `01: каркас проекта`.
- [ ] **02 — Каталог.** `build_catalog.py`, `films.json` (40–60 фильмов, 5+ казахстанских, id `f-001…`).
  Тест: `tests/test_catalog.py` — поля, типы, уникальные id, 5+ казахстанских, год/минуты целые.
  Коммит: `02: каталог films.json`.
- [ ] **03 — Схема и промпт.** `Pick`/`Choice`, `INSTRUCTIONS` с правилом про теги и одним примером, `build_messages`.
  Тест: `tests/test_prompt.py` — теги `<каталог>`, `<запрос>`, все названия через `ensure_ascii=False`.
  Коммит: `03: схема ответа и промпт`.
- [ ] **04 — Проверка id.** `check_ids(picks, films)` — чужой, повтор, больше трёх, пусто при `ok`.
  Тест: `tests/test_check_ids.py` — все случаи SPEC §5.2. Коммит: `04: проверка id кодом`.
- [ ] **05 — Журнал.** `log()` в `calls.jsonl`: `model`, `step`, `request` (запрос и id), `outcome`, `rejected`, `usage`, `usd`, `seconds`.
  Тест: `tests/test_log.py` — строка пишется, `request` не содержит всего каталога. Коммит: `05: журнал calls.jsonl`.
- [ ] **06 — `pick` и ошибки.** Вызов `client.chat.completions.parse`, ловля `APIConnectionError`, `APIStatusError`,
  `LengthFinishReasonError`, `refusal`, `ValidationError`; печать фильмов внутри `pick`.
  Тест: `tests/test_pick.py` — заглушка: верный ответ, чужой id, повтор, четыре id, `no_match`, отказ, обрезка, нет связи, 5xx,
  чужой каталог. Коммит: `06: pick, исходы и ошибки`.
- [ ] **07 — CLI и резерв.** `__main__`: чтение `films.json`, `.env`, облачный клиент и локальный, резерв при `no_connection`/`error_5xx`.
  Тест: `tests/test_main.py` — резерв включается, `pick` его не включает. Коммит: `07: запуск и резерв на локальную модель`.
- [ ] **08 — `show.py`.** Исходы, токены, цена по `calls.jsonl`. Тест: `tests/test_show.py` на маленьком журнале. Коммит: `08: show.py`.
- [ ] **09 — Набор запросов.** `queries.json` (15 запросов по SPEC §5.5). Тест: `tests/test_queries.py` — число и категории,
  id в `expect` из каталога. Коммит: `09: набор queries.json`.
- [ ] **10 — `check.py`.** Прогон набора, исходы, пойманные чужие id, доля с ожиданием.
  Тест: `tests/test_check.py` — подсчёт на заглушке. Коммит: `10: check.py`.
- [ ] **11 — Настоящие прогоны.** `uv run check.py` на qwen и на облаке: `calls.jsonl` наполняется. Коммит: `11: журнал настоящих прогонов`.
- [ ] **12 — Опыт с памятью.** `memory_test.py`: год и минуты 10 фильмов без каталога, число расхождений.
  Тест: `tests/test_memory.py` — сравнение на заглушке. Коммит: `12: опыт с памятью модели`.
- [ ] **13 — README.** Уровни, пять вопросов лекции 1, команды, вывод `check.py` и `show.py`, источник, опыт с памятью, ответы на 5 вопросов.
  Коммит: `13: README Common`.
- [ ] **14 — Проверка.** `kino_check.py` по коммиту: все S зелёные, `--live` проходит. Правки по результатам.

## Правила шага (DoD)

1. Тест написан первым и сначала падает.
2. `uv run pytest -q` зелёный, без реальной сети.
3. Один коммит на шаг, сообщение с номером шага.
4. Никаких заделов «на будущее»: только то, что требуют тесты шага.
